# ✍️ AutoPost v11.0

네이버 블로그 SEO 최적화 자동 글쓰기 + 🎬 유튜브 숏츠 대본 생성기

## 🎯 핵심 기능

### 1. ✍️ 블로그 포스트 (기존)
- SEO 85점 이상 자동 달성
- 제목 28-32자 + 키워드 포함
- 본문 1,500-3,000자
- 자동 재시도 (최대 3회)
- 키워드 타입 자동 판별 (거래/정보/일상/뉴스)
- 웹 검색 팩트 체크
- 영어 리라이트 (Google Blogger용)

### 2. 🎬 숏츠 대본 (NEW! v11.0)
- 성장서사 기반 유튜브 숏츠 대본 자동 생성
- 장면별 이미지 프롬프트 (Midjourney/DALL-E)
- TTS 최적화 스크립트
- 다국어 자막 (한/영/일/중) + SRT 다운로드
- 5개 카테고리: 역사 속 무명의 사람들 / 직업·기술 / 동물·자연 / 개념·발명품 / 가상 인물
- 4개 이미지 스타일: 수채화·지브리풍 / 세상의모든지식 / 플랫 일러스트 / 웜톤 애니메이션
- 3개 나레이션 톤: 따뜻한 감성 / 담담한 다큐 / 동화적 서술
- 저작권·초상권 완전 프리 설계

## 🚀 사용법

```
[블로그 포스트]
1. 키워드 입력 → 타입 자동 판별
2. 카테고리 선택
3. 생성 클릭 → SEO 85점 달성!

[숏츠 대본]
1. 주제 입력 (예: 1900년대 남해 등대지기)
2. 카테고리 / 톤 / 이미지 스타일 선택
3. 장면 수 / 자막 언어 선택
4. 생성 클릭 → 대본 + 프롬프트 + TTS + 자막 일괄 생성
```

## 📦 숏츠 제작 파이프라인

```
AutoPost 대본 생성 → Midjourney/DALL-E 이미지 → TTS 나레이션 → CapCut 편집 → 업로드
```

## 📂 파일 구조

```
main.py      — Streamlit UI + 생성 로직 (블로그 + 숏츠)
prompts.py   — 프롬프트 모음 (블로그 4종 + 영어 리라이트 + 숏츠 대본)
README.md    — 이 문서
```
